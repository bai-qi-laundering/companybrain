# 客衣攝影機（平板確認 + 待傳照片）

監視器掃到飯店 QR 後，依平板上的「洗前／洗後」模式把照片存到 companybrain，由該飯店 LINE 群組用指令把照片取出。拍照當下不會推播 LINE，以免占用官方帳號月配額。

## 平板確認頁

區網直接開（不需登入）：

`http://192.168.123.201:8790/`

同一個服務也聽在 `127.0.0.1:8790`，給本機的 Tailscale Funnel（或同類 HTTPS 反向代理）轉發。代理若把掛載路徑拿掉再轉進來，確認頁會出現在該埠的子路徑上，例如 `https://<主機>:8443/<子路徑>/`。子路徑權杖不要寫進版本庫，也不要提交到 GitHub。

`TABLET_PATH_PREFIX` 維持空白的兩種情況：只走區網根目錄，以及代理已經拿掉前綴。只有代理把完整路徑原樣轉給後端時，才把 `TABLET_PATH_PREFIX` 設成該前綴（格式見 `.env.example` 的範例，換成自己的路徑）。

加入主畫面或桌面時，請用結尾有斜線的網址。少了斜線的話，瀏覽器會把 `manifest.webmanifest` 和圖示算到上一層（Funnel 上那一層是別的服務）。頁面會自動補上斜線。manifest 的 `start_url`、`scope`、`id` 使用 `./`，圖示也用相對路徑，所以區網根目錄與子路徑都會從目前這頁啟動，並使用頁面上的綠色掛衣圖示。

iOS Safari、Android Chrome、桌面版 Chrome／Edge 都可以加入主畫面。Chrome／Edge 的「安裝應用程式」需要 HTTPS（例如 Funnel）。區網的 `http://` 仍可透過瀏覽器的加入主畫面使用同一份圖示與啟動網址。

從 LINE 點開連結時，LINE 內建瀏覽器沒有加入主畫面。頁面會提示改用 Safari 或 Chrome 開啟後再加入。

頁面上切換洗前／洗後，拍照成功會綠燈閃一下並發出提示音，並顯示最近紀錄。HTTP 區網下部分瀏覽器可能無法使用 Wake Lock；頁面本身仍可操作。

## LINE 取圖指令

在已綁定的飯店群組傳送（可接受全形 ＃，空白會被忽略；沒有 # 的文字不會觸發）：

- `#洗前客衣`
- `#洗後客衣`
- `#洗前制服`
- `#洗後制服`

每次回覆一則 CompanyBrain 相簿連結，包含當下所有符合條件的待傳照片。相簿沿用每張照片的保存期限。

管理員綁定／解除／查詢（`綁定H2O`、`解除綁定H2O`、`查詢綁定`）改為回覆，不再推播。

## 部署

將此目錄放到 NAS `/volume1/docker/garment-camera`（保留既有 `.env` 與 `data/`）。`.env` 不要提交到 GitHub。以 Container Manager 重建專案。

環境變數：`COMPANYBRAIN_URL`（HTTPS）、`CAMERA_API_KEY`、攝影機帳密。

## 照片保存

目前未改保存期限，現況請見主專案說明：companybrain 資料庫照片預設 24 小時後清除；本機 `data/photos` 的 JPEG 不會自動刪除。
