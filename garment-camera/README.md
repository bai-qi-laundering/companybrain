# 客衣攝影機（平板確認 + 待傳照片）

監視器掃到飯店 QR 後，依平板上的「洗前／洗後」模式把照片存到 companybrain，由該飯店 LINE 群組用指令把照片取出。拍照當下不會推播 LINE，以免占用官方帳號月配額。

## 平板確認頁

只綁在 NAS 區網 IP，不上 Funnel、不需登入：

`http://192.168.123.201:8790/`

可加到平板主畫面（PWA 風格）。頁面上切換洗前／洗後，拍照成功會綠燈閃一下並發出提示音，並顯示最近紀錄。HTTP 區網下部分瀏覽器可能無法使用 Wake Lock；頁面本身仍可操作。

## LINE 取圖指令

在已綁定的飯店群組傳送（可接受全形 ＃，空白會被忽略；沒有 # 的文字不會觸發）：

- `#洗前客衣`
- `#洗後客衣`
- `#洗前制服`
- `#洗後制服`

每次回覆最多 1 則說明 + 4 張圖。若還有剩餘，再傳一次同一指令。

管理員綁定／解除／查詢（`綁定H2O`、`解除綁定H2O`、`查詢綁定`）改為回覆，不再推播。

## 部署

將此目錄放到 NAS `/volume1/docker/garment-camera`（保留既有 `.env` 與 `data/`）。`.env` 不要提交到 GitHub。以 Container Manager 重建專案。

環境變數：`COMPANYBRAIN_URL`（HTTPS）、`CAMERA_API_KEY`、攝影機帳密。

## 照片保存

目前未改保存期限，現況請見主專案說明：companybrain 資料庫照片預設 24 小時後清除；本機 `data/photos` 的 JPEG 不會自動刪除。
