# companybrain

百麒公司往來管理前端。將 `index.html` 部署為靜態網頁即可使用，不需安裝套件。

- 管理總覽預設顯示待辦清單與月曆；對象名錄位於獨立頁面。
- 待辦支援新增、編輯、選填日期、勾選完成與日期篩選。
- 月曆標示未完成待辦的日期及數量，支援月份切換。
- 公司與合作對象檔案包含往來紀錄、合約價格、出差日期區間與關聯對象。

目前為前端體驗版，包含示範資料。紀錄與待辦儲存於本裝置的瀏覽器，尚未串接 NAS、登入、Gemini 或 LINE。不同網址的瀏覽器儲存互相獨立，切換網址不會自動搬移紀錄。

Gemini API 金鑰應設定在後端，請勿放入前端或提交到此 repository。
