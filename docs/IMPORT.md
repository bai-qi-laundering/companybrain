# 名錄編輯、分類與大量匯入

## 名錄與分類

在「對象名錄」新增或編輯對象時，「分類」可直接輸入新名稱，例如「管理層」「物流」「政府機關」。儲存後，新分類會出現在名錄篩選及其他對象的分類建議中。分類會隨對象存入 NAS；不必修改程式或環境設定。

如果表單開著時 LINE 或其他裝置新增了不相關的資料，儲存會自動合併並保留新資料。如果其他人同時修改同一筆對象，表單會顯示衝突原因並保留輸入內容。請先保留要修改的文字，關閉表單並重新載入，再確認最新內容。

價格欄可自由輸入，例如「鹽 50kg/包 $245」，不要求生效日。每行一項；已有「品項,單價,生效日」格式仍會顯示單價表，自由描述會原樣顯示在價格區塊。CSV 名錄可在「價格說明」欄填相同文字。

往來紀錄的每筆資料都有「刪除紀錄」，確認後才刪除該筆；取消不修改資料，其他紀錄與名錄不受影響。

## Excel 大量匯入

1. 登入 NAS 公司記憶庫，按上方「匯入資料」。
2. 選「對象名錄 CSV」「往來紀錄 CSV」或「待辦事項 CSV」。
3. 按「下載 CSV 範本」，用 Excel 開啟。
4. 保留第一列欄位名稱，用實際資料取代範例列，接著往下填，一列一筆。
5. 日期使用 `YYYY-MM-DD`，例如 `2026-10-15`。待辦日期、合約到期日與紀錄結束日期可留空；往來紀錄日期必填。
6. 另存為 **CSV UTF-8（逗號分隔）**，回到同一個匯入視窗，按「選擇檔案匯入」。不直接接受 `.xlsx`。
7. 檢查新增／略過筆數，確認後才寫入 NAS。任一列格式錯誤則整份不寫入，錯誤會顯示列號。

| 匯入內容 | 範本欄位 |
| --- | --- |
| 對象名錄 | 名稱、分類、聯絡人、職務、負責人、合約期間、合約到期日、備註、價格說明 |
| 往來紀錄 | 事項、日期、對象、紀錄類型、結束日期、關聯對象、金額、備註 |
| 待辦事項 | 事項、日期、備註 |

名錄的名稱與分類必填，其餘可留空；同名對象會略過，不覆蓋現有聯絡人或價格。往來紀錄的「對象」必須與已建檔名錄名稱完全相同，請先匯入名錄再匯入紀錄。紀錄類型可填客訴、人情往來、會議、報價、一般紀錄、出差／展覽、公司事項、人事，留空使用一般紀錄。金額請填純數字，不加貨幣符號。

待辦不要求名錄對象，直接填事項、日期與備註即可。CSV 不含照片或語音；相同 CSV 再次匯入會新增重複紀錄或待辦，請確認成功後不要重傳。

單檔最多3MB；名錄最多1000筆，往來紀錄與待辦各5000筆。

## JSON 備份匯入

「公司資料備份 JSON」可匯回「匯出資料」下載的檔案，依 ID 保留已有資料；同 ID 內容不同時會中止，不會覆蓋。照片與語音在 JSON 中只有附件連結，原始檔仍在原 NAS；完整移機與備份請用 `scripts/backup.sh` 產生資料庫備份。

## 直接新增 LINE 待辦

可傳「幫我加入10/15待辦：確認員工排班」或「明天待辦：去郵局」。明確單一日期加上「待辦」的內容會直接儲存，不依賴 AI，也不需名錄。只有月日時使用台灣日期的當年；跨年度請寫完整年份，例如「2027/1/3 待辦：拜訪親友」。若有多個日期或語意需要判斷，仍由 AI 整理。歷史紀錄的對象與日期確認規則不變。
